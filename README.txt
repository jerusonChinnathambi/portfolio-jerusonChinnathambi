JERUSON PAUL CHINNATHAMBI — PORTFOLIO WEBSITE
=============================================

HOW TO USE
----------
• To preview locally: double-click index.html (opens in your browser).
  The Spotify chart screenshots are embedded, so the gallery always shows.
  Research papers and your résumé open from the assets/ folder — keep
  index.html and the assets/ folder together.

• To publish online (recommended — makes everything one-click for visitors):
  Upload this whole folder to any static host:
    - GitHub Pages  : create a repo, upload these files, enable Pages
    - Netlify       : drag-and-drop this folder onto app.netlify.com/drop
    - Vercel        : import the folder
  Once hosted, every paper and your résumé open in a new tab on click.

FOLDER STRUCTURE
----------------
index.html                     ← the website
assets/JRSN_resume.pdf         ← your résumé (linked in nav + contact)
assets/papers/                 ← 5 research papers (linked in Research section)
assets/charts/                 ← 7 Spotify chart screenshots (also embedded)

UPDATING
--------
• Replace any PDF in assets/papers/ (keep the same filename) to update a paper.
• Swap assets/JRSN_resume.pdf to update your résumé.
